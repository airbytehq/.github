# Security Policy

Please do not report security vulnerabilities through public GitHub issues,
pull requests, or discussions.

Report vulnerabilities through the Airbyte Open Source Vulnerability
Disclosure Policy at https://airbyte.com/security/vdp, using the Airbyte Open
Source tab. You can also email your report to vdp-oss@airbyte.io.

When we publish a security advisory for this repository, it appears in its
Security tab.
